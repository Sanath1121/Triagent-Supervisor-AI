ℹ️  If you see a network or CORS error — click to read the fix

What is CORS? Your browser blocks this page from calling n8n (a different local address) as a security measure. This is called CORS — Cross-Origin Resource Sharing. It's not an error in your workflow; it's a browser restriction.

The fix (one line in your Docker config):

environment: - N8N_CORS_ALLOW_ORIGIN=*

Add that line under environment: in your docker-compose.yml, then run:

docker compose restart

After restarting, refresh this page and try again. The browser will now be allowed to call n8n.
